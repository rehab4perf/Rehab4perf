Ce que montre la maquette

  • Quatre sous-catégories au lieu d'une liste de dix lignes : Extension thoracique, Activation de la coiffe, Réponses de la coiffe, Contrôle scapulaire. Chacune se replie — la dernière est repliée à droite pour le montrer.
  • La recommandation vit sur la sous-catégorie, pas sur le test. C'est le point décisif : les cinq tests d'activation partagent une seule et même phrase dans le compte-rendu. L'afficher par test la répéterait cinq fois.
  • Le préfixe disparaît des libellés. « Activation coiffe - préhension » devient « Préhension » : la sous-catégorie porte déjà le mot. Dix lignes gagnent en lisibilité.
  • Une synthèse en pied de bloc reprend les pistes retenues — l'aperçu de ce qui partira dans le compte-rendu, sans avoir à l'ouvrir.
  • « Piste retenue », pas « déficit ». Dans ce bloc, positif est un signe favorable : le test dit qu'une stratégie fonctionne, donc qu'on peut la travailler. Le vocabulaire de la maquette respecte ce sens.

Une contrainte à connaître avant de coder

L'identité d'un test est son rang dans le catalogue : les réponses des bilans déjà enregistrés y sont rattachées par ce numéro. Le regroupement doit donc être uniquement visuel — même tableau, mêmes rangs, en insérant des en-têtes de groupe. Découper en plusieurs tableaux romprait le lien avec tous les bilans passés, qui afficheraient des réponses vides.

Ce que je n'ai pas tranché

Les recommandations sont aujourd'hui écrites en dur dans le générateur de compte-rendu. Pour les afficher ici, il faut les en extraire vers une table partagée — sinon les deux textes divergeront un jour. C'est le vrai travail de fond de ce chantier ; le reste est de la mise en forme.
